### 🚀 Featured Projects

#### ⚡ [JEV_Judge — Typed Decision Model & LLM Judge Alternative](https://github.com/Nefelim584/JEV_Judge)
> A ModernBERT-based decision model (`jev-lite`) outputting typed decisions (Bool / Choice / Score) with calibrated probabilities — designed as a fast, sub-100ms replacement for LLM-as-a-judge.

- **Architecture & Training:** Fine-tuned ModernBERT with LoRA & full parameter runs on dual Kaggle T4 GPUs; unified data pipeline via `uv`.
- **Statistical Rigor:** Comprehensive evaluation suite featuring paired bootstrap confidence intervals, McNemar significance testing, and black-box robustness probes (option-order invariance & IIA).
- **Model Weights:** Publicly released on [Hugging Face Model Hub](https://huggingface.co/Nefelim584/jev-lite-stage-a).
- **Stack:** `Python`, `PyTorch`, `Hugging Face Transformers`, `ModernBERT`, `uv`, `pytest`.

#### 🦀 [Daily_digest — Autonomous Local NLP Digest Engine](https://github.com/Nefelim584/Daily_digest)
> Autonomous AI & tech news digest engine built in pure Rust. Runs 100% locally with zero external API dependencies or subscription costs.

- **Algorithmic NLP:** TextRank graph centrality for extractive summarization and TF-IDF vector space clustering.
- **Backend & Delivery:** Asynchronous Axum REST API with task polling, webhooks, and containerized deployment with multi-stage Docker.
- **Stack:** `Rust`, `Axum`, `Tokio`, `Docker`, `TF-IDF / TextRank`.
